# 部分成交记录

本页提供“部分成交记录”的工程设计与验证检查表，供接入或维护相关模块时逐项审阅。

## 设计约束

每次成交应有独立记录，订单聚合值不能代替成交明细。

## 落地检查

### 1. 明确输入与边界

按上游成交标识去重保存明细。

### 2. 处理正常路径

累计成交量、成交额和费用。

### 3. 补齐确认与反馈

用订单聚合信息检查差异并触发补查。

## 典型失效模式

只保存最新成交会丢失累计成本。

## 验证场景

重复投递同一成交后，检查累计数量不变。

## 审阅问题

不同币种的手续费是否被直接相加？

## 评审记录

评审时记录适用模块、样本来源、验证结果及未解决项；尚未运行验证时标记为“待验证”，避免把设计建议当作已完成能力。
