# 交易所适配器边界

本页提供“交易所适配器边界”的工程设计与验证检查表，供接入或维护相关模块时逐项审阅。

## 设计约束

将上游接口差异限制在适配层，业务逻辑只消费统一模型。

## 落地检查

### 1. 明确输入与边界

定义行情、订单、余额三类端口及其输入输出。

### 2. 处理正常路径

在适配器内转换交易所字段与错误码。

### 3. 补齐确认与反馈

用固定响应样本验证转换，不发真实订单。

## 典型失效模式

不要把未知错误转换成成功或空列表。

## 验证场景

给出缺字段与未知状态样本，断言产生可识别错误。

## 审阅问题

更换交易所时，哪些业务模块仍需要修改？
