# 交易对与资产命名

本页提供“交易对与资产命名”的工程设计与验证检查表，供接入或维护相关模块时逐项审阅。

## 设计约束

内部标识应区分基础资产、计价资产、交易场所和产品类型。

## 落地检查

### 1. 明确输入与边界

定义结构化交易对标识。

### 2. 处理正常路径

维护内部标识与上游 symbol 的显式映射。

### 3. 补齐确认与反馈

找不到映射时拒绝请求并保留诊断信息。

## 典型失效模式

仅拼接资产代码会混淆现货与衍生品。

## 验证场景

用同名现货和永续产品验证不会命中同一个键。

## 审阅问题

映射表是否包含场所和产品维度？

## 评审记录

评审时记录适用模块、样本来源、验证结果及未解决项；尚未运行验证时标记为“待验证”，避免把设计建议当作已完成能力。
