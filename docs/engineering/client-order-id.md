# 客户端订单标识

本页提供“客户端订单标识”的工程设计与验证检查表，供接入或维护相关模块时逐项审阅。

## 设计约束

一次业务下单意图应拥有可追踪且符合上游限制的标识。

## 落地检查

### 1. 明确输入与边界

生成并持久化业务意图标识。

### 2. 处理正常路径

按交易所字符集和长度限制映射订单标识。

### 3. 补齐确认与反馈

重试前按标识查询，而非立即产生新意图。

## 典型失效模式

客户端标识的唯一性范围和保留期因接口而异。

## 验证场景

重复发送同一意图，验证不会直接创建第二个本地任务。

## 审阅问题

本地去重是否被误当成交易所提供的永久幂等？

## 评审记录

评审时记录适用模块、样本来源、验证结果及未解决项；尚未运行验证时标记为“待验证”，避免把设计建议当作已完成能力。
